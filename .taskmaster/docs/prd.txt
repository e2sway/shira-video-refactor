# Project Requirements: Video Feature Removal

## Project Overview
**Objective:** Remove all video-related functionality from the Shira learning app while preserving all non-video features including context quiz, cultural view, conversational practice, and progress tracking.

**Scope:** Refactor existing codebase to eliminate video dependencies while maintaining core learning functionality.

**Success Criteria:** 
- All video components, state, and dependencies removed
- Non-video learning features function identically to before
- App compiles and runs without video-related errors
- Database cleaned of video-specific data
- Reduced app bundle size from removed dependencies

---

## Phase 1: Project Preparation

### Requirements:
1. **Create backup strategy**
   - Create backup branch: `backup/video-features`
   - Commit current state with message: "Backup before video removal"
   - Create working branch: `refactor/remove-video`

2. **Backup critical files:**
   - `/shira_app/app/(tabs)/learn.tsx`
   - `/shira_app/app/learn-components/learnReducer.ts`
   - `/shira_app/app/learn-components/types.ts`
   - `/shira_app/supabase/contentService.ts`
   - `/shira_app/supabase/types.ts`

3. **Establish baseline functionality testing:**
   - Context Quiz: Navigate to learn tab, verify quiz loads, test answer submission
   - Cultural View: Verify content loads and box animations work
   - Conversational Practice: Test conversation flow and translations
   - Progress Tracking: Verify streak counter and daily goals
   - Navigation: Test tab switching and sidebar navigation
   - Audio Features: Verify expo-av audio functionality still works

**Acceptance Criteria:** All baseline features pass testing and backup branches are created successfully.
